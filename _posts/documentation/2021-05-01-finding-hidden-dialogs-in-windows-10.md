# {{ page.title }}

On my Windows machine running Windows 10 I had lost a dialog for an application. Well, it wasn't exactly lost. It somehow slithered out of one of my screens due to either resizing or some other intentional task I did with the monitors. Try as I might, I couldn't figure out how to retrieve it until Google solved it for me (isn't it true for all problems?).

Apparently this is a problem that occurs when using dual monitors. If you have ever lost a window or dialog for an application using Windows 10, you've probably wondered how it can possibly be found.

Well, you may probably find it by tabbing through the open applications using Alt + Tab but you might not be able to use your mouse pointer to grab the window and move it about. So, this is how I was able to catch the errant dialog.

## Method one - taskbar

1. From the taskbar, click application icon.
2. Press the **Windows** key plus the right or left arrow to snap the hidden dialog to the current screen.

## Method two - Alt + Spacebar + M

1. Press **Alt** + **Spacebar**.
2. Release the **Alt** key and the **Spacebar**, then press **M** (this selects the Move menu item on the dialog).
3. Use the left or right arrows to move the dialog into view on the current screen.

Hope this helps.
